# TROA Econ+ Support

Before reporting an issue, back up `TROA-Econ-Plus.cfg` and `TROA-Econ-PlusData`, then collect:

1. Exact command or integrating-plugin operation.
2. UTC server time and relevant Torch log lines.
3. Short Econ+ transaction ID or external reference.
4. State shown by `!econadmin recovery`.
5. Whether native balances changed for payer, payee, or treasury.
6. A sanitized configuration.

Never publish webhook URLs, tokens, complete private ledgers, or unrelated player data. Do not repeatedly retry a recovery-required transaction.
