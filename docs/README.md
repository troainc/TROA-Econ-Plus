# Econ+ Documentation

Use the guide that matches what you are trying to do:

- **I run the server:** start with [Server Owner Setup](SERVER-OWNER-SETUP.md), then use the [Configuration Guide](CONFIGURATION.md) and [Command Reference](COMMANDS.md).
- **I play on an Econ+ server:** use the [Player Guide](PLAYER-GUIDE.md). The commands actually available on your server are listed by `!econ help` in game.
- **Something is not working or you need to protect account data:** see [Troubleshooting and Data Safety](TROUBLESHOOTING.md).

The full public XML sample is [`TROA-Econ-Plus.cfg.example`](../TROA-Econ-Plus.cfg.example). Settings only work when your installed plugin build supports them; check the package version and [changelog](../CHANGELOG.md).

## Start here

Read the [detailed user and operator guide](USER_GUIDE.md) for supported setup, feature workflows, safe operation, and troubleshooting.
